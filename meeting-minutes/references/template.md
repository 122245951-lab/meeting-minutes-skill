## 有用户模板：回填规则
用户上传了模板（文本 / md / docx / pdf 均可）时，**以模板为准**组织纪要：
1. **保留模板结构**：固定文案、段落顺序、表格结构、字段名、标题层级一律不改。
2. **回填内容**：把 Step 3 提取的要素与内容填入模板对应字段；模板字段与提取字段不同名时做语义映射（如模板写"出席人员"对应"参会人"）。
3. **决议三件套**：模板决议章节若为表格/列表，按"决策事项 / 决策人 / 决策依据"回填；模板只有单一"决议"字段时，按"事项（决策人/依据）"并入该字段。
4. **模板中不存在的环节**：模板没有"风险"但内容有风险时，不擅自加段——先在问答环节询问用户是否需要补充。
5. **缺失字段**：模板有但内容提取不到 → 进问答兜底。
6. **模板样式**：交付飞书文档时保持模板的样式与版式；**行业风格仅调整语言表达，不改变模板结构**。

## 无模板：自动生成匹配模板
用户未提供模板时，**自动生成匹配的模板骨架**：
1. **确定会议类型**：按 SKILL.md Step 3.5 的选择结果，从 `meeting-types.md` 预置清单套用对应骨架；类型不明用「通用例会」。
2. **应用行业风格**：按 `industry-styles.md` 调整语言基调、用词与字段侧重。
3. **自定义适配**：素材中有骨架未覆盖的重要内容（如财报、排期表），可增加相应小节，但先问用户是否保留。
4. **填入内容**：把提取结果按骨架结构写入，生成完整纪要。
5. **决议三件套**：骨架中决议章节按"决策事项 / 决策人 / 决策依据"组织。
6. **待确认事项独立输出**：素材含"待确认/待核实/待定/需反馈"等未落定事项时，无论详略档位，都在纪要末尾追加「待确认事项」独立章节，每条含**事项内容 / 跟踪人 / 预期解决时间**三字段；素材没有则不输出该章节。
7. **交付增强**：按 `delivery.md` 输出一键三件套（速览卡/正式纪要/行动项清单）、后果推演提示与来源标注。

## 详略自适应
按转录/素材长度决定详略（以正文有效字数估算）：

| 档位 | 触发条件 | 内容范围 |
| --- | --- | --- |
| 精简版 | 素材 < 约 500 字 | 五要素 + 决议结论 + 待办事项 |
| 标准版 | 约 500 – 3000 字 | 五要素 + 议程 + 发言要点 + 决议 + 待办 + 风险 |
| 详细版 | > 约 3000 字 | 标准版全部 + 分议题展开要点细节、争议过程、逐项决议 |

若用户明确指定详略（"简单点""写详细些"），以用户要求为准，覆盖默认规则。
**例外**：「待确认事项」为条件输出章节，不受详略档位削减——素材有即输出，没有则不输出。

## 缺失字段问答兜底
- **时机**：模板字段、待办负责人/截止时间、会议要素等在内容中找不到时。
- **方式**：汇总所有缺失项成**一次确认列表**，一次性发给用户。示例：
```
以下信息在素材里没有找到，请补充或确认（没有就回"没有"）：
1. 会议地点：？
2. 参会人：？（已知：王磊、李雪）
3. 待办"整理需求清单"的负责人：？
4. 决议"下周开始开发"的决策人 / 依据：？
5. 待确认事项"数据口径待财务确认"的跟踪人 / 预期解决时间：？
6. 模板中"风险"一栏：素材未提及，是否保留该节？
```
- **留空规则**：用户答"没有 / 不知道 / 不用" → 对应字段**留空**（标「待补充」或直接留空），绝不编造。
- **范围限制**：只问真正影响纪要完整性的字段；不逐字段轰炸、不问不必要的问题。
- **日期豁免**：日期缺省默认当天，不进入问答（用户主动要求改除外）。

## 自定义模板保存与复用

### 保存触发
用户本次上传了模板并完成回填后，**主动询问**是否保存为个人预设：
```
这个模板要保存为个人预设吗？保存后下次可以直接用模板名调用。
请给模板起个名字（如"团队周会模板"），或回复"不保存"。
```
用户命名后，将模板结构（字段名、段落顺序、表格结构、固定文案）保存为个人预设，记录以下元数据：
- **模板名称**：用户指定的名称
- **适用会议类型**：推断或用户确认的类型
- **适用行业**：推断或用户确认的行业
- **创建时间**：保存日期
- **字段清单**：模板包含的所有字段及是否必填

### 复用方式
用户下次调用时，可通过以下方式引用已保存的模板：
- 直接说"用我之前的『团队周会模板』"
- 说"用上次那个模板"（引用最近一次保存的模板）
- 在 Step 3.5 模板选择环节，列出用户已保存的模板供选用

复用已保存模板时，按「有用户模板：回填规则」严格执行，不再重新询问模板结构。

### 管理
- 用户可要求"列出我的模板"查看已保存模板清单。
- 用户可要求"删除『XX模板』"移除不再需要的预设。
- 模板保存在用户个人空间，不与其他用户共享。

## 模板市场

### 概念
模板市场是预置的优质会议纪要模板集合，供用户在无自定义模板时选用。与 `meeting-types.md` 的自动骨架不同，模板市场中的模板是**经过设计的完整成品模板**，含固定文案、表格样式、字段定义，适合对纪要格式有较高要求的场景。

### 预置模板清单（示例，可持续扩充）

| 模板名称 | 适用场景 | 特点 |
| --- | --- | --- |
| 董事会纪要模板 | 公司董事会、股东会 | 正式公文风格，含出席/缺席/列席、议案逐条表决、决议公告式表述 |
| 项目评审会模板 | 立项评审、方案评审 | 含评审维度打分表、评委意见汇总、通过/修改/驳回结论栏 |
| 客户拜访纪要模板 | 对外商务沟通 | 含客户方/我方人员分列、客户需求清单、我方承诺、跟进计划 |
| 敏捷迭代规划会模板 | 互联网研发团队 | 含 Story Point 估算、迭代 Backlog、容量规划、依赖关系 |
| 季度经营分析会模板 | 管理层经营复盘 | 含 KPI 达成表、同比环比、问题归因、下季度 OKR |
| 学术组会模板 | 科研团队、实验室 | 含文献汇报、实验进展、数据讨论、下周计划 |
| 法务合规审查会模板 | 法律、合规部门 | 含条款逐条审查、风险等级、合规意见、整改要求 |

### 使用方式
- 在 Step 3.5 模板选择环节，除了"自动生成骨架"和"个人预设"，增加"从模板市场选用"选项。
- 用户指定市场模板名称时，直接加载该模板并按回填规则执行。
- 用户未指定但会议类型与某市场模板高度匹配时，可推荐："检测到这是董事会场景，是否使用『董事会纪要模板』？"
- 模板市场模板与个人预设不冲突：个人预设优先级高于市场模板。

### 扩展
- 用户可将自己保存的优质模板"发布到模板市场"（需确认是否共享），丰富模板库。
- 新增市场模板时，需填写模板名称、适用场景、特点说明，并附完整模板结构。
