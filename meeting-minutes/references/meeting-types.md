# 会议类型预置清单

用户未指定会议类型时，从内容推断并在以下预置清单中匹配；类型不明确时用「通用例会」骨架。
每个类型含**识别特征**（用于推断）与**模板骨架**（无用户模板时的默认结构）。

## 通用规则（所有骨架适用）
- **决议三件套**：骨架中的决议/最终结论章节，统一按"决策事项 / 决策人 / 决策依据"组织；模板无法拆分多条时合并为一条主决议。
- **待确认事项**：素材中若存在"待确认/待核实/待定/需反馈"等未落定事项，在骨架末尾追加「待确认事项」独立章节，每条含 **事项内容 / 跟踪人 / 预期解决时间** 三字段；素材没有则不输出该章节。
- **交付增强**：一键三件套、后果推演提示、来源标注见 `delivery.md`。

## 通用例会（默认）
- **识别特征**：日常碰头、无法归入其他类型的会议。
- **骨架**：
```
【会议纪要】{主题}（{日期}）
一、会议信息：时间 / 地点 / 参会人 / 主持人
二、会议议程
三、讨论要点
四、决议结论（决策事项 / 决策人 / 决策依据）
五、待办事项（事项 / 负责人 / 截止时间 / 状态）
六、风险与遗留问题
七、待确认事项（事项内容 / 跟踪人 / 预期解决时间）※素材有才输出
```

## 项目周会 / 项目例会
- **识别特征**：周期性同步项目进展、上周完成、下周计划、排期、里程碑。
- **骨架**：
```
【项目周会纪要】{项目名}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、本周进展（按成员或模块）
三、上周待办完成情况
四、问题与风险
五、下周计划与排期
六、新待办事项（事项 / 负责人 / 截止时间 / 状态）
```

## 项目启动会 / 立项会
- **识别特征**：新项目启动、目标、范围、分工、里程碑、资源。
- **骨架**：
```
【项目启动会纪要】{项目名}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、项目背景与目标
三、项目范围与边界
四、组织分工（角色 / 负责人）
五、里程碑与计划
六、资源与依赖
七、风险与前置条件
```

## 决策会
- **识别特征**：对某议题做选择、拍板、定方案、给结论。
- **骨架**：
```
【决策会纪要】{议题}（{日期}）
一、会议信息：时间 / 地点 / 参会人 / 决策人
二、决策背景与目标
三、备选方案与讨论
四、最终决策及理由（决策事项 / 决策人 / 依据）
五、决策落地安排（负责人 / 时间）
六、风险与后续跟进
```

## 方案 / 设计评审会
- **识别特征**：对方案、设计稿、技术方案评审，给出通过/修改/驳回意见。
- **骨架**：
```
【评审会纪要】{评审对象}（{日期}）
一、会议信息：时间 / 地点 / 参会人 / 评审人
二、评审范围与材料
三、评审意见（通过项 / 修改项 / 驳回项）
四、修改要求与时间
五、复审安排
```

## 需求评审会
- **识别特征**：评审需求、讨论功能点、确认范围、排期。
- **骨架**：
```
【需求评审纪要】{需求/项目}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、需求范围与优先级
三、需求澄清与讨论
四、确认结论（通过 / 调整 / 驳回，含决策依据）
五、排期与责任人
六、待确认问题
```

## 复盘会
- **识别特征**：对项目/活动/事件做回顾、总结得失、改进。
- **骨架**：
```
【复盘会纪要】{项目/事件}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、目标回顾与结果对比
三、做得好的 / 问题与不足
四、原因分析
五、改进措施（措施 / 负责人 / 时间）
```

## 客户沟通会 / 商务会议
- **识别特征**：对外沟通、客户需求、商务条款、合作。
- **骨架**：
```
【客户沟通纪要】{客户/项目}（{日期}）
一、会议信息：时间 / 参会人（我方 / 客户方）
二、客户需求与反馈
三、我方回应与方案
四、达成的共识
五、后续跟进事项（事项 / 负责人 / 截止时间）
```

## 每日站会
- **识别特征**：短平快、每人讲昨天/今天/阻塞。
- **骨架**：
```
【每日站会纪要】{项目}（{日期}）
一、参会人
二、昨日完成
三、今日计划
四、阻塞与求助
```

## 头脑风暴会
- **识别特征**：发散想法、创意、点子收集、不急于拍板。
- **骨架**：
```
【头脑风暴纪要】{主题}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、主题与目标
三、创意与想法汇总（分类整理）
四、可行性与优先级初判
五、下一步行动
```

## 培训 / 分享会
- **识别特征**：知识分享、培训讲解、经验传递。
- **骨架**：
```
【培训/分享纪要】{主题}（{日期}）
一、会议信息：时间 / 地点 / 讲师 / 参会人
二、内容要点
三、提问与解答
四、资料与后续安排
```

## 季度 / 年度总结会
- **识别特征**：周期性总结、指标回顾、下阶段规划。
- **骨架**：
```
【总结会纪要】{周期/主题}（{日期}）
一、会议信息：时间 / 地点 / 参会人
二、阶段目标回顾与达成
三、成果与亮点
四、问题与不足
五、下阶段目标与计划
六、待办事项（事项 / 负责人 / 截止时间 / 状态）
```

> 以上骨架为默认起点，实际生成时按素材内容微调章节名称；**行业风格**见 `industry-styles.md`，**交付增强**见 `delivery.md`。
