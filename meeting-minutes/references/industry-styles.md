# 行业风格预置清单

不同行业的会议纪要风格不同。用户指定行业时按其风格写；未指定时从内容中的行业术语/业务背景推断，并把推断结果给用户确认或改选；无法判断时用「通用」风格。

**应用原则**：行业风格只影响**表达方式、正式度与内容侧重**，不改变、不新增会议事实；行业术语仅在素材中出现或用户确认时使用，不自行编造术语。

## 行业明细

### 互联网 / 科技
- **基调**：简洁直接，少客套，数据与事实说话。
- **结构**：进展 → 问题 → 决策 → 待办，弱化仪式感章节。
- **用词**：迭代、版本、灰度、上线、排期、ROI、数据指标。
- **侧重**：版本进度、上线时间、数据表现、技术风险。

### 金融 / 银行
- **基调**：正式严谨，术语规范，合规与风险意识贯穿。
- **结构**：决策 → 风险提示 → 落地安排。
- **用词**：授信、敞口、合规审查、风控、监管要求、数据口径。
- **侧重**：风控结论、合规要求、资金与数据口径、监管事项。

### 医疗 / 医药
- **基调**：严谨规范，法规导向，表达审慎。
- **结构**：合规 → 进展 → 风险。
- **用词**：注册、临床（GCP）、质量体系、不良反应、药监要求。
- **侧重**：法规合规、临床进展、质量与安全性、受试者相关事项。

### 制造 / 工业
- **基调**：务实直接，强调执行与结果。
- **结构**：进度 → 质量 → 安全 → 交期。
- **用词**：交期、良率、产能、安全生产、供应链、设备。
- **侧重**：生产进度、质量问题、安全事项、交期承诺。

### 建筑 / 地产
- **基调**：工程导向，阶段与节点表述清晰。
- **结构**：进度 → 成本 → 质量 → 验收。
- **用词**：节点、签证、竣工验收、整改、成本、安全。
- **侧重**：工程进度节点、成本控制、安全文明施工、验收整改。

### 政府 / 事业单位
- **基调**：公文风格，正式规范，决议与部署表述准确。
- **结构**：决议 → 部署 → 责任落实。
- **用词**：会议部署、落实、督办、责任到人、时间要求。
- **侧重**：决议事项、工作部署、责任分工、完成时限。

### 教育
- **基调**：简明清晰，教务导向。
- **结构**：教务 → 学生 → 课程 → 活动。
- **用词**：教学计划、教务、学生工作、课程安排、活动。
- **侧重**：教学安排、学生事务、课程调整、活动组织。

### 零售 / 电商
- **基调**：数据导向，节奏快，结果明确。
- **结构**：销售 → 库存 → 促销 → 平台。
- **用词**：GMV、转化率、大促、库存周转、投放、平台规则。
- **侧重**：销售数据、库存与补货、促销活动、平台政策。

### 咨询 / 专业服务
- **基调**：结论先行，结构化，客户导向。
- **结构**：结论 → 交付 → 行动项 → 承诺。
- **用词**：交付物、里程碑、行动项、客户承诺、时间承诺。
- **侧重**：交付进度、客户需求、行动项与负责人、时间承诺。

### 法律 / 合规
- **基调**：精确审慎，条款导向。
- **结构**：条款 → 风险 → 合规 → 期限。
- **用词**：条款、违约、合规审查、期限、责任。
- **侧重**：条款约定、法律风险、合规事项、期限节点。

### 快消 / 品牌市场
- **基调**：创意与数据结合，营销导向。
- **结构**：品牌 → campaign → 渠道 → 效果。
- **用词**：campaign、种草、投放、转化、预算、渠道。
- **侧重**：品牌动作、营销活动、渠道与预算、投放效果。

### 通用（默认）
- **基调**：中性书面，清晰易读。
- **结构**：标准五段（信息/议程/要点/决议/待办/风险）。
- **侧重**：平衡呈现所有会议内容，不做行业侧倾。

## 应用规则
1. **风格与骨架配合**：会议类型（`meeting-types.md`）决定骨架结构；行业风格（本文件）决定同一骨架内的语言基调、用词与字段侧重。
2. **不改变事实**：调整的是表达方式与详略侧重，会议结论、数字、待办、日期等事实不变。
3. **术语谨慎**：仅使用素材中出现的行业术语；素材没有且不确定时，用通用表述，不硬造术语。
4. **正式度适配**：政府/金融/医疗/法律偏正式；互联网/电商/快消可更简洁直接；拿不准时用中性书面。
