# meeting-minutes · 会议纪要生成与可视化 Skill

把一堆原始会议素材 —— 语音转文字全文、自己记的杂乱笔记、上传的会议文件 —— 整理成一份**结构化、可直接交付的正式会议纪要**，并一键产出四件套：速览卡 / 正式纪要 / 行动项清单 / 可视化卡片。需要走签批归档流程时，可再追加一份表格型 Word 制式纪要（两页 A4 内）。

不是简单的"把话重说一遍"。它会补全纪要该有的东西：谁拍的板、依据是什么、待办归谁、什么时候到期、哪些事还没落定。

---

## 它能做什么

**输入**
- 语音转文字全文（含说话人标签的话会额外做角色识别）
- 自己记的零散笔记、要点草稿
- 会议文件：`.txt` / `.md` / `.docx` / `.pdf`
- 用户自己的纪要模板（有模板就严格按模板回填）

**处理**
- 清洗去重、去口头语、合并碎片笔记、纠正转录错别字
- 相对时间（"本周二""下周五"）按当前日期换算成具体日期，并标注 已过期 / 临近 / 未到期
- 提取会议五要素 + 六类内容（议程 / 发言要点 / 决议结论 / 待办事项 / 风险遗留 / 待确认事项）
- 会议类型自动匹配模板骨架：周会、决策会、评审会、复盘会、启动会、站会等
- 行业风格切换语言基调：互联网、金融、医疗、制造、政府、教育、电商等
- 中英混合素材自动检测主语言，专业术语保留原文
- 缺失字段一次性问答兜底，用户说"没有"就留空，**不编造**

**输出（一键四件套 + 可选第五件）**
| 产物 | 给谁看 |
|---|---|
| 一页速览卡 | 管理层，一屏看完核心信息 |
| 正式纪要 | 存档，含决议三件套、待确认事项、来源标注、后果推演提示 |
| 行动项清单 | 执行层，待办 + 待确认合并表格，含状态 |
| 可视化卡片 | 静态 HTML 一页卡片，图形化呈现核心结论与待办状态 |
| Word 制式纪要（**可选**） | 要走签批 / 盖章 / 归档流程时用：表格型、两页 A4 内、带签批栏。四件套交付后主动询问，**不默认生成** |

## 几个设计上的坚持

- **决议三件套**：每条决议都要有「决策事项 / 决策人 / 决策依据」。没有依据的决议，等于没记。
- **待确认事项独立成节**：「待定」「待核实」「再看看」这类没落定的事，单独列出事项内容 / 跟踪人 / 预期解决时间，不混进决议里充数。
- **事实来源标注**：关键事实在正文括号标注来自素材哪一段，方便回溯。
- **后果推演提示**：只基于素材里已有的关联做推断，且明确标注这是推断，不是事实。
- **日期兜底**：内容里没日期就默认当天，不拿这个去烦用户。
- **默认不留发言人**：合并成整体叙述；除非用户要求保留，保留时附带识别出的角色标签。
- **Word 版不新增信息**：它是同一份提取结果的精简投影 —— 不新增事实、不新增推断、不新增素材里没提到的因果；超两页就按压缩优先级裁剪重生成，绝不交付超页版本。

## 目录结构

```
.
├── meeting-minutes/              # Skill 本体
│   ├── SKILL.md                  # 主流程与规则
│   └── references/               # 分模块详细规则
│       ├── extraction.md         #   素材清洗、要素与内容提取、来源定位、发言人角色识别
│       ├── template.md           #   模板回填、自动生成、详略自适应、模板保存与模板市场
│       ├── meeting-types.md      #   会议类型预置清单（识别特征 + 模板骨架）
│       ├── industry-styles.md    #   行业风格预置清单（语言基调 + 字段侧重）
│       ├── language.md           #   多语言混合处理
│       ├── delivery.md           #   四件套交付、后果推演提示、来源标注
│       ├── visual-card.md        #   可视化卡片输出规范
│       └── word-minutes.md       #   Word 制式纪要规范（可选第五件 · 表格型 · 两页 A4 内）
└── examples/
    └── meeting-visual-card-demo.html   # 可视化卡片成品示例
```

## 安装

把 `meeting-minutes/` 整个文件夹放进你的 skills 目录即可：

```bash
# 用户级（所有项目可用）
cp -r meeting-minutes ~/.workbuddy/skills/

# 项目级（仅当前项目）
cp -r meeting-minutes .workbuddy/skills/
```

## 使用

直接说人话就行：

```
帮我生成会议纪要
把这段转录整理成纪要
按这个模板写会议纪要
整理一下刚才的会议记录
```

想指定得更细：

```
按周会模板整理，金融行业风格
用英文输出，专业术语保留原文
保留发言人维度
```

Skill 会在缺关键信息时**一次性**列出缺失字段问你，答"没有"就留空。

## 依赖

- 交付环节使用飞书云文档（`lark-doc`）承载四件套
- Word 制式纪要用 **python-docx** 生成，不依赖 Word COM / pandoc
- 文件读取依赖：`.docx` → `lark-doc`，`.pdf` → 对应 PDF skill，录音转写 → 用户明确要求时才调用
